This is an automation of automatically claiming the rewards for Grow As Anomaly. 
Basic guide to use this, you'll need to meet the following requirements:

Screen resolution of: 1920x1080 (Scaling set 100%)
A Windows OS

Note that this script only works in fullscreen. And does not provide any malicious software or harming of one's system.
