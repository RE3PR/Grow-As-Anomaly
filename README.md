# Grow As Anomaly

This is a working personal project for **Grow As Anomaly**, created to provide macro functionality and ease-of-use features.

## Requirements
- Windows OS
- Display resolution: 1920x1080
- Display scaling: 100%

## Included

- **Auto Claim Rewards** — A folder containing features to automatically claim rewards and milestones.
